# Figures: what each one shows and where it goes

Fifteen figures are generated by `python -m tools.make_figures` into `docs/img/`
as SVG and PDF (Okabe–Ito palette, serif + computer-modern maths, LNCS-safe at
one-column width). The paper prose currently references only Figure 1, so this
file is the placement map — without it a figure that took a day to get right
never reaches the reader.

`make_figures` refuses to draw from a `report.json` whose recorded digests no
longer match `config/`, so a figure in `docs/img/` is either current or absent.
Regenerate after any re-freeze.

## Placement

| # | file | section | what it shows | why it earns its space |

## If space forces a cut

At twenty pages with fourteen paper figures, something goes. In order of what we
would drop first:

1. `corpus-pipeline` — the text in §8.1 carries it.
2. `invisibility-gate` — the four gate checks are already a short list in §3.
3. `evsi-decay` — §9.3's table makes the same point with measured numbers.

Keep `decision-bands`, `holdout-effect`, `recall-forest` and
`recall-by-category` under any budget: they carry the derivation, the causal
estimate, the headline and the mechanism respectively, and each is doing work no
paragraph in the paper duplicates.
